# Nexora — Modern Angular SaaS Admin Dashboard & Template

**Nexora** is a clean, production-ready enterprise admin and dashboard template built with Angular. It features an integrated Dark & Light mode toggle powered by `angular-dark-mode`, a modular component structure, a real-time Notification Center, security Audit Logs, and a comprehensive suite of pre-built screens to kickstart your next SaaS application.

---

## ✨ Included Pages & Features

* **Authentication Portal:** Complete secure authentication suite including Login, Create Account (Sign Up), and Password Reset views.
* **Core Dashboard Overview:** High-performance summary featuring key metrics, revenue/growth trend charts, and recent transaction logs.
* **User Management:** Comprehensive table layout with search filtering, role tags (Admin, Editor, Member, Billing), status indicators, and Add New User actions.
* **Billing & Subscription:** Subscription plan management, active billing overview, saved credit card handlers, and downloadable past invoice history.
* **Analytics & Reports:** Deep-dive reporting with user acquisition trends, traffic source metrics, bounce rates, conversion funnels, and custom date filters.
* **Pricing Plans:** Transparent pricing tiers (Starter, Professional Pro, Enterprise Scale) with a monthly/yearly billing toggle and custom options.
* **Security Audit Logs:** Enterprise compliance view tracking user activities, IP addresses, categories, and system security events.
* **Interactive Notification Center:** Real-time dropdown notification panel accessible via the top navigation bell icon for unread alerts.
* **Settings & Errors:** Account profile settings, security password updates, notification preferences, and a clean 404 Not Found error page.
* **Theme Support:** Native Dark and Light mode switching with instant state persistence and system preference synchronization.

---

## 🛠️ Prerequisites

Before running the project locally, ensure you have the following installed:
* **Node.js** (v14+ recommended)
* **Angular CLI** (`npm install -g @angular/cli`)

---

## 🚀 Getting Started (Installation & Setup)

Follow these steps to set up the project locally:

1. **Clone or Extract the Project:**
   Unzip the template package and open your terminal inside the root project directory (`Nexora`).

2. **Install Dependencies:**
   Run the following command to install all required npm packages including the dark mode manager:
   ```bash
   npm install --legacy-peer-deps

```

3. **Run the Development Server:**
Execute the following command to spin up the local server:
```bash
ng serve

```


Navigate to `http://localhost:4200/` in your browser.
